# 📝 React Todo App with API (TypeScript & Bulma)

A production-ready Task Management application (Todo App) built with **React** and **TypeScript**. The project integrates with a remote REST API, implements clean architectural patterns, and ensures high code quality using strict linting tools.

🚀 **[LIVE DEMO](https://mark-chep.github.io/Todo_App/)**

---

## ⚡ Key Features

* **Full CRUD Lifecycle:** Seamlessly create, read, update, and delete tasks with real-time server synchronization.
* **REST API Integration:** Robust server communication, including loading states management, error handling, and dynamic user notifications upon network failure.
* **Advanced Filtering:** Sort tasks by *All*, *Active*, and *Completed* states, featuring bulk status toggling and clearing completed items.
* **Clean Architecture:** Clear separation of logical layers with dedicated directories for server requests (`api/`), business logic (`use_cases/`), enumerations (`enums/`), and strict typing (`types/`).
* **Modern UI/UX:** Responsive and clean interface powered by the **Bulma CSS** framework, enhanced with custom **SCSS** and **FontAwesome** icons.

---

## 🛠️ Tech Stack & Tools

* **Core:** React 18 (Functional Components, Hooks)
* **Language:** TypeScript (Strict typing, Custom Interfaces, Enums)
* **Styling:** Bulma CSS Framework & SCSS (Modular layout)
* **Build Tool:** Vite
